Buatlah sebuah media pembelajaran interaktif berbasis HTML, CSS, dan JavaScript untuk mata pelajaran Matematika SMA dengan materi **TRIGONOMETRI**. **A. Tujuan Pembelajaran** Siswa mampu: 1. Memahami konsep dasar trigonometri. 2. Mengidentifikasi sisi depan, sisi samping, dan sisi miring pada segitiga siku-siku. 3. Memahami perbandingan sinus, cosinus, dan tangen. 4. Menghitung nilai sin, cos, dan tan pada sudut istimewa. 5. Memahami konsep lingkaran satuan (unit circle). 6. Menyelesaikan permasalahan kontekstual menggunakan trigonometri. **B. Materi Pembelajaran** 1. Pengertian dan sejarah singkat trigonometri. 2. Perbandingan trigonometri pada segitiga siku-siku. 3. Rumus SOH-CAH-TOA. 4. Sudut istimewa: 0°, 30°, 45°, 60°, dan 90°. 5. Identitas dasar trigonometri. 6. Lingkaran satuan. 7. Penerapan trigonometri dalam kehidupan sehari-hari. **C. Fitur Interaktif** 1. Halaman pembuka yang menarik. 2. Menu navigasi setiap materi. 3. Visualisasi segitiga siku-siku yang dapat diubah sudutnya. 4. Simulasi perubahan nilai sinus, cosinus, dan tangen. 5. Lingkaran satuan interaktif. 6. Tabel sudut istimewa. 7. Contoh soal beserta pembahasan langkah demi langkah. 8. Latihan soal pilihan ganda dengan 10 soal. 9. Skor otomatis dan umpan balik jawaban. 10. Kesimpulan dan refleksi pembelajaran. **D. Desain** - Gunakan desain modern, menarik, dan responsif. - Gunakan warna biru, putih, dan ungu. - Gunakan animasi ringan. - Sertakan grafik dan visualisasi matematika. - Gunakan bahasa Indonesia yang mudah dipahami siswa SMA. - Rumus matematika harus ditampilkan dengan jelas. - Pastikan tampilan nyaman digunakan melalui laptop maupun HP. **E. Ketentuan Teknis** - Seluruh kode HTML, CSS, dan JavaScript berada dalam satu file HTML. - Tidak membutuhkan database. - Dapat dijalankan secara offline. - Semua tombol dan simulasi harus berfungsi. - Gunakan JavaScript untuk menghitung nilai trigonometri secara langsung. - Pastikan tidak terdapat kesalahan perhitungan. Hasil akhir berupa satu file bernama `trigonometri.html` yang siap digunakan sebagai media pembelajaran di kelas.
